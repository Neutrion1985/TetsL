# TetsL — сайт для проходження тестів

Простий вебсайт на **Python + Flask + SQLite**, де користувачі можуть:

- зареєструватися (власний логін і пароль; паролі зберігаються у вигляді хешу);
- увійти / вийти;
- проходити тести з питаннями та варіантами відповідей;
- бачити свій результат з розбором правильних/неправильних відповідей;
- переглядати історію своїх спроб («Мої результати»).

**Адміністратор** (ним автоматично стає *перший* зареєстрований користувач) може:

- створювати тести та додавати питання (2–6 варіантів, один правильний);
- видаляти питання й тести;
- переглядати результати всіх користувачів за кожним тестом.

При першому запуску автоматично створюється демонстраційний тест «Загальні знання».

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Відкрийте http://127.0.0.1:5000 у браузері.

## Налаштування

| Змінна оточення     | Призначення                                       | За замовчуванням        |
|---------------------|---------------------------------------------------|-------------------------|
| `TETSL_DB`          | Шлях до файлу бази даних SQLite                   | `tetsl.db` поруч з app.py |
| `TETSL_SECRET_KEY`  | Секретний ключ для сесій                          | генерується у `.secret_key` |
| `FLASK_DEBUG=1`     | Режим налагодження (тільки для розробки)          | вимкнено                |

Для публічного розгортання використовуйте WSGI-сервер, напр.:
`pip install gunicorn && gunicorn -w 2 -b 0.0.0.0:8000 app:app`

## Структура бази даних

`users` → `attempts` (спроби) → `answers` (обрані відповіді);
`tests` → `questions` → `options` (варіанти, позначка `is_correct`).
